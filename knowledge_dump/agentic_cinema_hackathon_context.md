## 🎬 Overview & Theme

The hackathon is framed around a **cinematic studio metaphor**. Participants take on one of three roles:

- **Director** — Building production-ready autonomous agent networks
- **Technical Producer** — Connecting secure data pipelines via managed MCP servers
- **Studio Head** — Enforcing Cloud IAM security and governance across multi-agent workflows

The core challenge is to use **Gemini Enterprise Agent Platform (Google Cloud)** and a **partner technology** to build agentic AI workflows targeting real media & entertainment bottlenecks — for filmmakers, screenwriters, studio crews, or fans.

## 🛠️ What to Build

Build a **functional, production-ready AI agent or multi-agent network** that:

- Is **powered by Gemini and Google Cloud Agent Builder**
- **Integrates a Partner Entity's product or MCP server**
- Solves critical bottlenecks across the **entertainment and media value chain**
- Targets workflows of **filmmakers, screenwriters, studio crews, or fans**

## 📋 Submission Requirements

Every submission must include:

1. **Hosted Project URL** — A live, accessible URL to the running project
2. **3-Minute Demo Video** — Shows the agent functioning; uploaded to YouTube or Vimeo, publicly visible, in English or with English subtitles. Max 3 minutes (only first 3 evaluated if longer)
3. **Public Code Repository** — GitHub, GitLab, or Bitbucket with:
   - All source code, assets, and run instructions
   - Must demonstrate actual runtime use of Google Cloud AND the chosen Partner's service (imported and called in code, not just mentioned in README)
   - Must be **public** with a detectable **open-source license** at the top of the repo (About section)
4. **Partner Track Selection** — Declare which of the 5 partner tracks you're entering
5. **Completed Devpost Form** — Text description including: summary of features/functionality, technologies used, data sources, findings and learnings

### Accepted Google Cloud SDK packages
`google-adk`, `google-genai`, `google-generativeai`, or `google-cloud-aiplatform`

### Per-Track Partner Requirements

| Track | Mandatory Runtime Requirement |
|---|---|
| **IBM** | Must use **IBM Bob** as part of the development process. Confluent optional but encouraged. Must show how AI improves a workflow, decision-making, CX, or operational outcome. |
| **Grafana Labs** | Must actively use **Grafana Cloud MCP server** (`grafana/mcp-grafana` or hosted Grafana Cloud MCP endpoint) at runtime, exposing 60+ tools for metrics/logs/traces/dashboards/alerts. Grafana Cloud AI Observability alone does not satisfy this. |
| **Parallel** | Must actively use **Parallel's Search API** at runtime via `parallel-web` SDK (Python/TypeScript), Vercel AI SDK's `@parallel-web/ai-sdk-tools`, LangChain's `ParallelWebSearchTool`, or Grounding config using Parallel Web Search. Must be in code, not just README. |
| **Clickhouse** | Must actively use **ClickHouse at runtime** via official ClickHouse MCP server (`mcp-clickhouse`), connecting to ClickHouse Cloud or self-hosted cluster. ClickHouse Agent Skills optional but encouraged. |
| **Replit** | Must be built using **Replit Agent** as part of the development process AND **deployed/hosted on Replit** (URL on `replit.app` or `replit.dev` domain). Not deployed on Replit = disqualified. |

## ⚖️ Judging Criteria (Stage 2 — Equal Weight)

| Criterion | Description |
|---|---|
| **Technological Implementation** | How well is the project built? How effectively does it use Google Cloud and the Partner services? |
| **Design** | Does it deliver a complete, coherent product experience — not just a technical proof-of-concept? |
| **Potential Impact** | Does it make a credible, specific case for solving a real problem for a real audience? Does it address it based on what's demonstrated? |
| **Quality of the Idea** | Is it a creative, non-obvious use of Google Cloud and Partner services? Does the team show genuine understanding of the problem space? |

### Judging Stages

- **Stage 1 (Pass/Fail):** Baseline viability check — all submission requirements present, reasonably addresses the challenge, and applies required Partner + Google Cloud products. May use automated tools.
- **Stage 2:** Full evaluation against the 4 criteria above (equal weight). Highest-scoring submissions per track become potential winners. Ties broken by criteria order, then judge vote.

- Maximum **4 individuals** per team
- One team member must be the designated **Representative** for submission
- An individual can submit to **multiple tracks** with unique, substantially different projects
- Projects must be **newly created** during the contest period (July 27 – September 9, 2026)

---

## ⛔ AI Tool Restriction (Critical)

Projects may **only use Google Cloud AI tools** (Gemini models on Agent Platform, BigQuery ML, relevant APIs) and the built-in AI features of the chosen partner product. **No other AI models, agent frameworks, or AI APIs are permitted**, including:

- AWS AI services
- Microsoft Azure AI
- OpenAI
- **Anthropic** (Claude, etc.)

This restriction applies only to AI/agent tooling. Non-AI third-party services (hosting, databases, standard web frameworks) are allowed.
